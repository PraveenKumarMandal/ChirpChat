# ChirpChat

ChirpChat is a modern real-time messaging application built with React Native (Expo), Node.js, Express, MongoDB, and Socket.IO. It provides a secure and fast communication experience with features inspired by popular messaging platforms.

## Features

-  Secure Email OTP Authentication
-  User Registration & Login
-  Profile Photo Upload
-  Friend Requests & Friend Management
-  Real-Time One-to-One Messaging
-  Typing Indicators
-  Message Delivery & Read Receipts
-  Image & File Sharing
-  Block Users
-  Light & Dark Theme
-  Cross-Platform (Android & Web)

## Tech Stack

**Frontend**
- React Native (Expo)
- TypeScript
- Expo Router

**Backend**
- Node.js
- Express.js
- MongoDB
- Socket.IO
- JWT Authentication
